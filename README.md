# Neo Cyberpunk Audio Visualizer (Web)

Live audio-reactive wallpaper page. Host on GitHub Pages; pair with the
"Tab Audio → Live Wallpaper Bridge" Chrome extension to visualize a tab's audio.
Without audio it runs its idle animation (planets orbiting, particles floating).

Settings (⚙, top right): text, colors, glitch, debug HUD, sensitivity — saved locally.
Based on the original Lively Wallpaper project (see LICENSE).

## Get audio into it (Chrome / Edge)

Install the companion extension: https://github.com/siliconvalley007/Neo-Audio-Visualizer-Chrome-Extension
(follow its README, ~1 minute), then open this page and press Start in the extension while on your music tab.

## Host your own copy

Fork this repo → Settings → Pages → Deploy from branch `main` / root.
