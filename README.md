# Neo Cyberpunk Audio Visualizer (Web)

A live-wallpaper-style audio visualizer that runs in your browser. Press **F11**
for fullscreen. **Live:** https://siliconvalley007.github.io/Neo-Cyberpunk-Audio-Visualizer-Web/

![Preview](preview.gif)

With no audio it runs its idle animation (orbiting planets, floating particles).
Settings (⚙, top right): text, colors, glitch, debug HUD, sensitivity, saved locally.

## Get audio into it (Chrome / Edge)
Install the **[Neo Audio Visualizer Bridge](https://github.com/SiliconValley007/Neo-Audio-Visualizer-Chrome-Extension)**
extension (about 1 minute; follow its README), open this page, then press Start in the extension while on your music tab.

## Host your own copy
Fork this repo → Settings → Pages → Deploy from branch `main` / root.
If you host your own copy, also update the URLs in the extension's `manifest.json`.
